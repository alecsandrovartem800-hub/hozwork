# SPORT LOUNGE — Умная система управления кальянной

> Полностью автономная система управления кальянной: умное распределение заказов, управление табаками, два Telegram-бота, админ-панель с KPI.

## 🌿 Возможности

### Умное распределение заказов
- Автоматическое назначение свободного мастера
- Очередь с расчётом времени ожидания
- Автоотмена зависших заказов по таймауту
- Real-time обновления через Socket.IO

### Управление табаками
- Учёт остатков в граммах
- Автосписание при выполнении заказа
- Автозаявки при снижении ниже порога
- Кнопка «Добавить в наличие» — пополнение в один клик

### Админ-панель
- Дашборд с KPI (заказы, выручка, мастера, запасы)
- Управление заказами + очередь
- Клиенты с персональными ценами (500/750/1000₽)
- Табаки + заявки на пополнение
- Атмосфера (музыка, свет, температура)
- Smart Features (тумблеры автоматизации)

### Два Telegram-бота
- **Бот поддержки**: чат с гостями + вызов мастера
- **Бот заказов**: карточки заказов с кнопками подтверждения/отмены/цены

## 🛠️ Стек

| Компонент | Технология |
|-----------|-----------|
| Frontend | Next.js 16 + Tailwind CSS v4 + Zustand |
| Backend | Node.js + Express + Socket.IO + TypeScript |
| Database | Supabase (PostgreSQL) |
| Telegram | grammy (2 бота) |
| Deploy | GitHub Actions → Cloudflare Pages + сервер |

## 🚀 Быстрый запуск

### 1. База данных (Supabase)
Выполните в SQL Editor панели Supabase:
```sql
-- 1. Создание таблиц
-- Скопируйте содержимое database/schema.sql

-- 2. Политики безопасности
-- Скопируйте содержимое database/rls_policies.sql

-- 3. Начальные данные
-- Скопируйте содержимое database/seed.sql
```

### 2. Бэкенд
```bash
cd server
cp .env.example .env   # Заполните ключи (или используйте готовый .env)
npm install
npm run dev
```
Сервер запустится на `http://localhost:3001`

### 3. Telegram-боты
1. Найдите ботов в Telegram:
   - Бот поддержки: отправьте `/start`
   - Бот заказов: отправьте `/start`
2. Боты автоматически сохранят ваш Chat ID

### 4. Фронтенд
```bash
cd frontend
npm install
npm run dev
```
Откройте `http://localhost:3000`

### 5. Админ-панель
Перейдите на `http://localhost:3000/admin`

## 🤖 Smart Features

| Функция | Описание |
|---------|----------|
| Авто-назначение | Свободный мастер автоматически получает заказ |
| Авто-отмена | Зависшие заказы отменяются через 30 мин |
| Авто-заявки | При низком остатке табака создаётся заявка |
| Скрытие пустых | Вкусы с 0г скрываются из меню |
| Оценка ожидания | Гости видят расчётное время |
| Telegram-заказы | Карточки заказов в Telegram |
| Telegram-поддержка | Чат с гостями через бота |
| KPI-снимки | Ежедневная статистика |

## 📊 API Endpoints

| Метод | Путь | Описание |
|-------|------|----------|
| GET | /api/orders | Список заказов |
| POST | /api/orders | Создать заказ |
| PATCH | /api/orders/:id/status | Обновить статус |
| PATCH | /api/orders/:id/price | Установить цену (админ) |
| GET | /api/tobacco/flavors | Вкусы табака |
| GET | /api/tobacco/flavors/by-brand | Вкусы по брендам |
| GET | /api/masters | Список мастеров |
| GET | /api/dashboard | KPI данные |
| GET | /api/restock | Заявки на пополнение |
| POST | /api/restock/:id/fulfill | Пополнить запас |
| GET | /api/atmosphere | Настройки атмосферы |
| GET | /api/smart | Smart Features |
| GET | /api/liquids | Жидкости для кальяна |
