# HOZWORK — Хозяйственные товары

HOZWORK — это полностью готовая к работе веб-платформа (интернет-магазин) по продаже хозяйственных товаров, ориентированная на максимальную автоматизацию бизнес-процессов, безопасность расчётов и интеллектуальный анализ данных.

## 🌟 Ключевые особенности проекта

1. **Залоговая система (Mandatory Prepayment)**
   При оформлении заказа клиент сразу вносит обязательный залог в размере **30%** от стоимости заказа (имитируется Mock платежным шлюзом). Остальная сумма оплачивается при получении.

2. **Политика невозвратности заказов**
   Согласно бизнес-логике, подтвержденные и оплаченные залогом заказы **обмену, возврату и отмене не подлежат**. Это четко отображено на всех этапах покупки (в корзине, при оформлении заказа и в личном кабинете).

3. **Встроенный Чат поддержки**
   Прямая связь с продавцом по каждому заказу. Интегрирована подписка на обновления сообщений в реальном времени через Supabase Realtime.

4. **Автоматический Telegram-Бот**
   Администратор мгновенно получает подробные уведомления о новых заказах и статусах доставки. Бот работает в режиме длинного опроса (polling), что позволяет ему функционировать локально без настройки SSL/вебхуков.

5. **9 Научных Модулей Аналитики (Scientific Skills)**
   Интегрированные модули прогнозирования продаж (регрессия), сравнения категорий (ANOVA), интеллектуальных рекомендаций товаров (коллаборативная фильтрация и графы связей NetworkX), автогенерации PDF-накладных с QR-кодами, SEO-описаний и проведения A/B-тестов.

---

## 🛠️ Стек технологий

- **База данных**: Supabase (PostgreSQL, Row Level Security, Realtime).
- **Бэкенд**: FastAPI (Python 3.10+, Pydantic v2, HTTPX, ReportLab, Scipy, Numpy, Scikit-learn, NetworkX, Plotly).
- **Фронтенд**: Next.js 14+ (React, Zustand, Tailwind CSS v4, TypeScript, React Plotly).

## 🚀 Быстрый запуск

### Шаг 1: База данных (Supabase)
Запустите файлы в редакторе SQL в панели управления Supabase в следующем порядке:
1. `database/schema.sql` — Создание таблиц.
2. `database/rls_policies.sql` — Настройка прав доступа и политик RLS.
3. `database/seed.sql` — Первоначальное наполнение каталога (20 товаров).

### Шаг 2: Настройка Бэкенда (FastAPI)
1. Перейдите в папку бэкенда:
   ```bash
   cd backend
   ```
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Запустите API-сервер:
   ```bash
   uvicorn app.main:app --reload --port 8000
   ```

### Шаг 3: Активация Telegram-Бота
1. Найдите вашего бота в Telegram и напишите ему `/start`.
2. Бот отправит приветственное сообщение и автоматически зарегистрирует ваш аккаунт администратора для получения уведомлений.

### Шаг 4: Настройка Фронтенда (Next.js)
1. Перейдите в папку фронтенда:
   ```bash
   cd frontend
   ```
2. Установите пакеты:
   ```bash
   npm install
   ```
3. Запустите Next.js сервер:
   ```bash
   npm run dev
   ```
4. Откройте `http://localhost:3000` в браузере.
